# DockFolders v1 (shell version)

This is the original zsh implementation, kept for reference and for people who prefer a
dependency-based CLI (`dockutil`, `fileicon`, Python Pillow).

The current version lives in the repository root: a native macOS app with a GUI and a
dependency-free CLI. It imports a v1 `config.sh` automatically (`dockfolders import`).

```bash
cd legacy
./install.sh
dockfolders organize
```
